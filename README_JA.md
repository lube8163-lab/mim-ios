# Mim iOS アプリ

Mim は **semantic communication（意味による通信）** を実験する iOS 向けソーシャルアプリです。

ユーザーは画像そのものを配信するのではなく、  
選択した画像から抽出された「意味情報」を共有し、  
受信側のデバイス上で AI によってビジュアルを再構築します。

> データではなく、意味を送る。

## 🌱 Mim が目指していること

一般的な SNS では、画像や動画などの大きなバイナリデータを直接送信します。

Mim は異なるアプローチを試みます。

- 画像から意味的な情報を抽出する  
- コンパクトな意味表現を共有する  
- 受信側デバイス上でビジュアルを再生成する  

この仕組みにより、

- 生データの共有を減らす  
- プライバシー性を高める可能性を探る  
- 意味中心のコミュニケーションモデルを検証する  

ことを目的としています。

---

## 主な機能

- テキストや画像を用いた投稿の作成
- 選択した画像からの意味情報抽出
- Stable Diffusion を用いた画像再構築（モデルインストール時）
- 生成中は低解像度ガイド画像を表示
- タイムライン閲覧、いいね機能

---

## 安全対策・UGCモデレーション

Mim はユーザー生成コンテンツ（UGC）を扱うアプリとして、以下の安全対策を実装しています。

- 投稿前にメール登録（OTP認証）を必須化
- 初回起動時に利用規約・プライバシーポリシーへの同意が必要
- 投稿の通報機能（Timeline > Post menu > Report）
- ユーザーブロック機能（Timeline > Post menu > Block User）
- ブロックしたユーザーの投稿はフィードに表示されません
- 投稿前のキーワードスクリーニング
- 通報内容は確認のうえ適切に対応（削除・アカウント対応等）

---

## プライバシー

- 写真へのアクセスは `PhotosPicker` 経由のみ
- ユーザーが選択した画像のみ処理対象
- バックグラウンドでのフォトライブラリアクセスなし
- 意味抽出・画像生成処理は主にオンデバイスで実行
- トラッキングSDKは含まれていません

---

## モデルおよびバックエンド

- 本リポジトリは iOS クライアントのソースコードを含みます
- AIモデルはアプリ内で任意ダウンロード方式
- 各モデルはそれぞれのライセンスに従います
- フィード・ユーザー管理・モデレーションにはバックエンドサービスを使用しています
