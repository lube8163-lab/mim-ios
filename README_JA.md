# Mim サポート・規約サイト

このリポジトリは、公開済みのMimアプリのサポートページ、プライバシーポリシー、利用規約を管理します。

- [App Store](https://apps.apple.com/app/mim/id6756841673)
- [公開iOSクライアントのソースと技術資料](https://github.com/lube8163-lab/mim-ios-app)
- [サポートページ](index.html)
- [プライバシーポリシー](privacy.html)
- [利用規約](terms.html)

アプリ開発元とバックエンド運用は別管理です。このリポジトリにはバックエンド実装、認証情報、運用状態を含めません。モデルの重みは各モデルのライセンスに従い、ソースコードとは別に配布します。

旧 `SemanticCompression-v2-public` はアーカイブ、`semantic-compression-demo` は過去の独立したデモです。現行の公開クライアントは `mim-ios-app` を参照してください。

既存のサポート・規約URLは維持します。対応OSやモデル構成、実測性能はクライアント側の資料に集約しています。
