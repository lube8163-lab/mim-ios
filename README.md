- [日本語](README_JA.md)

Application development and backend operations are managed separately. Backend implementation, credentials and operational state are not published in this repository. Model weights retain their upstream licenses and are distributed separately from client source.

`SemanticCompression-v2-public` is the archived predecessor. `semantic-compression-demo` is a separate historical demonstration. Use `mim-ios-app` for the current public client instead of treating these repositories as interchangeable copies.

The existing support and legal URLs are retained. Current platform requirements, model configuration and measured performance are documented in the client repository; this website repository does not maintain a second technical specification.
