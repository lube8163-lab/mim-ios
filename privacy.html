Privacy Policy for Mim

Effective Date: 2026/02/08

Mim is a privacy-focused experimental social application that allows users to share content using semantic and low-data representations instead of full-resolution images.

Information We Collect

  • Account information provided by the user (such as email address and username)
  • User-generated content representations (such as semantic tags, metadata, and selected privacy-mode data)
  • Optional profile images explicitly uploaded by the user
  • Basic diagnostic and usage data necessary for app functionality and stability

Privacy-Focused Image Handling

Mim is designed with data minimization in mind. Original full-resolution images selected by users are processed on-device and are not uploaded to the server for feed posting.

When a user creates a post, the app transmits only limited representations depending on the selected privacy mode, which may include:

  • Non-reversible semantic representations (e.g., tags or embeddings)
  • ThumbHash or similar low-information representations
  • Optional low-resolution images (e.g., 64×64 Base64), only if explicitly selected by the user

These representations are used solely to display content in the feed and to enable on-device reconstruction. Full-resolution original photos are not transmitted to external AI services.

On-Device AI Processing

Image analysis and reconstruction are primarily performed on the user’s device using on-device AI models. Mim does not use third-party AI APIs to process user images or personal data.

Third-Party Services and Data Sharing

Mim does not sell, rent, or share personal data with third-party AI services.

The app uses Cloudflare infrastructure (including Workers, D1, and R2) solely for secure data storage, synchronization, and content delivery. These services function as hosting and backend infrastructure and do not perform AI analysis on user content.

No user personal data or images are sent to external AI providers such as OpenAI, Stability AI, or similar services.

Profile Images

Profile icons are uploaded only when explicitly selected by the user. If no profile image is set, no image is stored for the profile.

How We Use Information

  • To provide and operate the core features of the app
  • To display user posts and reconstructed content
  • To maintain account functionality and security (including OTP authentication)
  • To improve stability, safety, and user experience

User Consent and Control

Users must agree to the Privacy Policy and Terms of Service before using core features of the app. The app records consent status and timestamp for transparency.

Users explicitly choose a privacy mode before posting content. Higher reconstruction modes may transmit low-resolution representations only after user selection.

Users may request deletion of their account and associated data at any time.

Data Security

All data is transmitted using secure communication protocols (HTTPS). Reasonable technical and organizational measures are implemented to protect user data.

Tracking and Advertising

Mim does not track users across third-party apps or websites. Mim does not use third-party advertising networks and does not sell user data.

Changes to This Policy

This Privacy Policy may be updated as the app evolves. Continued use of the app after updates constitutes acceptance of the revised policy.
